# TV Show Episode Recreation — Production Strategy

> Turning an entire TV episode into a ~1-minute AI-generated recap with multiple recurring characters — do not choose a tool simply because it makes the prettiest single clip.

---

## Important Requirements

- Multiple characters in the same scene
- Characters remaining recognizable across shots
- Dialogue / narration
- Lots of scene changes
- ~60 seconds final video
- Reasonably cinematic quality
- Ability to produce many episodes efficiently

## Production Approach

> **Don't try to generate the entire 1-minute recap in one prompt.**

For this kind of content, build a 60-second video from roughly **8–15 shots**.

### Example Shot Breakdown

| Timecode   | Shot Description                    |
| ---------- | ----------------------------------- |
| 0 – 5 sec  | Establish protagonist + location    |
| 5 – 11 sec | Character A confronts Character B   |
| 11 – 16 sec | Reaction shot                      |
| 16 – 23 sec | Flashback                          |
| 23 – 30 sec | Villain enters                     |
| 30 – 37 sec | Argument                           |
| 37 – 44 sec | Important plot event               |
| 44 – 52 sec | Reaction / consequence             |
| 52 – 60 sec | Cliffhanger + narration            |

Each shot is generated independently while using **reference images / character sheets** to keep the cast consistent. This is much more reliable than asking:

> *"Create a 60-second summary of Breaking Bad S01E01."*

---

## Pipeline Design

Since this involves many episodes across different shows, it becomes a **content-generation system**, not just an AI video generator.

### Step 1 — Episode → Script

Take the episode and produce structured scene descriptions:

```yaml
Scene 1:
  Characters: Walter, Jesse
  Location:   Desert
  Action:     Walter confronts Jesse
  Narration:  "Walter realizes the situation has become dangerous."

Scene 2:
  Characters: Walter
  Location:   RV
  Action:     Walter examines the equipment
  Narration:  "But he has already committed to the plan."

Scene 3:
  Characters: Walter, Jesse
  Location:   Desert
  Action:     ...
```

### Step 2 — Create a Character Bible

For each show, define consistent character descriptions:

```
Walter
  - Male, 50s
  - Bald, glasses, mustache
  - Beige jacket
  - Consistent facial structure

Jesse
  - Male, 20s
  - Short brown hair
  - Red hoodie
```

Then **generate reference images** for each character. Recent tools increasingly support reference-based character consistency — Runway explicitly provides workflows around consistent characters and locations.

### Step 3 — Generate Shots

- **Kling 3.0** as the workhorse — its multi-shot approach supports up to six shots within a generation and reference elements for maintaining specific characters.
- **Veo 3.1** for particularly important shots where you want maximum visual quality and/or generated dialogue/audio.

### Step 4 — Assemble

```
Episode
   ↓
LLM
   ↓
60-sec script
   ↓
Shot list
   ↓
Character references
   ↓
Kling / Veo
   ↓
8–15 clips
   ↓
Voiceover
   ↓
Music / SFX
   ↓
Captions
   ↓
Final 60-sec video
```

## Legal Considerations

> **Don't necessarily recreate the actual TV characters.**

If your intention is to publish commercially, literally generating *"Walter White from Breaking Bad"* or reproducing recognizable actors/characters/scenes invites copyright, trademark, and likeness/voice rights issues.

**Safer approach:**

> *"Create an original character visually inspired by a middle-aged chemistry teacher in a crime drama."*

Your recap can tell the story archetype without reproducing the actual actors. If the goal is specifically "AI-generated recaps of existing TV episodes", design the workflow around the legal/content risks as well as the generation technology.

## Recommended Starting Stack

| Role                | Tool         | Why                                       |
| ------------------- | ------------ | ----------------------------------------- |
| **Main production** | Kling 3.0    | Character/reference consistency + multi-shot |
| **Premium shots**   | Veo 3.1      | High-quality visuals + dialogue/audio      |

> Do not build the whole system around Veo alone — the bottleneck is **consistent recurring characters** across dozens/hundreds of shots, not whether an individual 8-second clip looks good. Google's documentation currently describes Veo clips as ~8 seconds, with emphasis on reference/extension capabilities.
